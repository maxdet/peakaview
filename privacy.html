Privacy Policy – Peak A View Uploader

Last updated: 29 September 2026

Peak A View Uploader ("the app") is a private, single-user tool operated by Maxime de Techtermann, Udligenswil, Switzerland. It uploads timelapse videos of the Alps to the Peak A View YouTube channel, which he owns.

Who uses the app

Only the channel owner. The app is not offered to the public and no other person can sign in to it.

What data the app accesses

Through Google OAuth, the app gets access to the owner's own YouTube channel using the YouTube Data API scopes youtube.upload and youtube. It uses these only to upload videos, set their titles, descriptions, thumbnails and publish times, and add them to playlists on that channel. It also reads basic channel information (channel ID and title) to confirm it is posting to the correct channel.

What data is stored

The OAuth token is stored only on the owner's private home server. The app keeps a local log of uploaded video IDs and publish dates. It does not collect, store, sell or share any data about other YouTube users or viewers.

Third parties

The app uses YouTube API Services. By using YouTube you are subject to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. When the app is retired, the stored token is deleted.
